# 問い合わせURL

iOS / Android アプリ「クロノクイズ」の問い合わせリポジトリです。

問い合わせ事項がありましたら [Issues](https://github.com/ry-yoshida-dev/ry-yoshida-dev.github.io/issues) にてご投稿をお願いいたします。
[Googleフォーム](https://forms.gle/BEzYrUfyfPPRDdWB9) からもお問合せを受け付けます。

## プライバシーポリシー

最終更新日: 2026年8月16日

本ポリシーは、個人開発者 ry_yoshida（以下「当方」）が提供するアプリ「クロノクイズ」（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

### 1. 当方が取得する情報

本アプリは、氏名・住所・電話番号・メールアドレスなど、利用者を直接特定する情報を取得しません。取得するのは以下の情報に限られます。

#### 1-1. オンライン対戦機能を利用する場合

| 情報 | 内容 |
| --- | --- |
| 匿名ID | 端末ごとに自動発行される識別子です。アカウント登録は不要で、当方が利用者本人を特定することはできません。 |
| ニックネーム | 利用者が入力した12文字以内の表示名です。同じルームに参加した他の利用者に表示されます。 |
| ゲームの記録 | ルーム番号、出題された問題の識別子、各参加者の解答した西暦、残りHPなど、対戦の進行に必要な情報です。 |
| プレイ回数の残数 | 無料でプレイできる残り問題数と、その付与日の記録です。 |

これらは Google LLC が提供する Firebase Authentication（匿名認証）および Firebase Realtime Database に保存されます。

#### 1-2. 広告の配信に関する情報

本アプリは、Google AdMob を通じて広告を配信しています。AdMob および提携する広告事業者は、広告の表示・配信・効果測定のために、広告識別子（IDFA / AAID）、IP アドレス、おおよその位置情報、端末情報などを取得することがあります。

これらの情報は広告事業者が直接取得するものであり、当方が受け取ることはありません。詳細は [Google のプライバシーポリシー](https://policies.google.com/privacy) および [広告におけるデータ利用](https://policies.google.com/technologies/partner-sites) をご確認ください。

#### 1-3. 取得しない情報

本アプリはアクセス解析ツールを導入していません。また、一人用・みんなであそぶモードのみをご利用の場合、当方のサーバーへ送信される情報はありません。ゲームの設定や進行状況は端末内にのみ保存されます。

### 2. 利用目的

- オンライン対戦において、参加者を識別し、同じゲームを進行させるため
- 無料でプレイできる残数を管理するため
- 広告を表示し、アプリの提供を継続するため
- お問い合わせに回答するため

### 3. 情報の保存場所（国外への移転）

オンライン対戦の情報は、Google LLC が管理する **シンガポール** のサーバー（Firebase Realtime Database, asia-southeast1）に保存されます。日本国外への個人関連情報の移転にあたりますので、オンライン対戦をご利用の際はこの点にご同意いただいたものとして取り扱います。

移転先の Google LLC における個人情報保護の取り組みについては、[Google のプライバシーポリシー](https://policies.google.com/privacy) をご参照ください。

### 4. 保存期間と削除

- **ルームの情報**：ホストが退出した時点で削除されます。また、一定期間利用のないルームは自動的に削除されます。
- **プレイ回数の残数**：本アプリを削除すると匿名 ID は端末から失われ、当方から当該記録を参照する手段はなくなります。
- **削除のご依頼**：ニックネームなど特定のデータの削除をご希望の場合は、下記の窓口までご連絡ください。ただし、当方は利用者本人を特定できないため、削除対象の特定にはルーム番号など手掛かりとなる情報のご提供をお願いすることがあります。

### 5. 第三者への提供

当方が取得した情報を、法令に基づく場合を除き第三者へ提供することはありません。

ただし、上記のとおり本アプリは以下の外部サービスを利用しており、それぞれの事業者が定めるポリシーに従って情報が取り扱われます。

| サービス | 提供者 | ポリシー |
| --- | --- | --- |
| Google AdMob | Google LLC | https://policies.google.com/technologies/ads |
| Firebase | Google LLC | https://firebase.google.com/support/privacy |

### 6. 広告に関する利用者の選択

- **iOS**：初回起動時に、トラッキングの許可を求める画面を表示します。許可しない場合でも本アプリのすべての機能をご利用いただけます。設定はいつでも iOS の「設定」→「プライバシーとセキュリティ」→「トラッキング」から変更できます。
- **Android**：広告 ID のリセットおよびパーソナライズ広告のオプトアウトは、端末の「設定」→「Google」→「広告」から行えます。
- **欧州経済領域・英国・スイスの利用者**：初回起動時に同意画面を表示します。同意内容は、タイトル画面の「Privacy settings」からいつでも変更できます。
- パーソナライズ広告の一括設定は [Google の広告設定](https://adssettings.google.com) からも行えます。

### 7. お子様の利用について

本アプリは特定の年齢層を対象としたものではなく、13歳未満のお子様を主たる対象としていません。13歳未満のお子様から意図的に情報を取得することはありません。

### 8. 本ポリシーの変更

本ポリシーの内容は、法令の変更やアプリの機能追加に応じて改定することがあります。重要な変更を行う場合は、本ページにて告知します。
