## プライバシーポリシー

最終更新日: 2026年10月4日

本ポリシーは、個人開発者 ry_yoshida（以下「当方」）が提供するアプリ「平成プロフ」（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

### 1. 当方が取得する情報

本アプリは、利用者の情報を一切取得しません。

本アプリはインターネットへの通信を行わず、アカウント登録、広告、アクセス解析ツールのいずれも利用していません。利用者が入力した内容や選んだ写真が、当方や第三者のサーバーへ送信されることはありません。

### 2. 端末内に保存される情報

本アプリで作成するプロフィールの内容は、利用者の端末内にのみ保存されます。

| 情報 | 内容 |
| --- | --- |
| 入力した内容 | 名前、自己紹介、すきなもの、フリースペースの書き込みなど、プロフィールに入力した内容です。 |
| プロフィール写真 | 写真ライブラリから選んだ写真の複製です。保存されるのは最新の1枚のみで、写真を選び直すと以前の写真は削除されます。 |
| デザインの設定 | 選んだデザインと配色です。 |

これらの情報は、本アプリを削除すると端末から消去されます。当方がこれらの情報を参照することはできません。

### 3. 写真ライブラリの利用

- **写真を選ぶとき**：システムの写真選択画面を利用します。本アプリが受け取るのは、利用者が選んだ写真のみです。写真ライブラリ全体へアクセスすることはありません。
- **画像を保存するとき**：作成したプロフィール画像を写真ライブラリへ追加するために、写真の追加の許可を求めます。この許可は保存のためだけに使い、写真ライブラリ内の写真を読み取ることはありません。

### 4. 共有について

作成したプロフィール画像は、利用者の操作により、端末の共有機能を通じて他のアプリへ送ることができます。共有先での画像の取り扱いは、共有先のサービスのポリシーに従います。

### 5. お子様の利用について

本アプリはお子様にもご利用いただけます。本アプリは利用者の情報を取得しないため、お子様の情報が当方へ送信されることはありません。作成した画像を共有する際は、保護者の方とご一緒にご利用ください。

### 6. 本ポリシーの変更

本ポリシーの内容は、法令の変更やアプリの機能追加に応じて改定することがあります。重要な変更を行う場合は、本ページにて告知します。
